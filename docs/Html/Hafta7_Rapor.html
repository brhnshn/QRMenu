9) Performans ve Canli Ekran Iyilestirmeleri (Hafta 7 Sonu Ek 2)

Oturum Dogrulama ve Istek Yuku Kritik

  • ✓Token dogrulama akisinda middleware tarafinda 60 sn refresh throttle uygulanarak gereksiz DB write yuku azaltildi.
  • ✓Siparis/Sepet akisinda controller ici tekrar token validate adimi kaldirildi, HttpContext uzerinden oturum okuma standardize edildi.
  • ✓Personel cookie + musteri token ayni tarayicida oldugunda sepet/siparis 401 sorunu middleware akisi duzeltilerek giderildi.

Veri Erisim ve Arsiv Performansi Iyilestirme

  • ✓Admin siparis arsivinde server-side sayfalama (page/pageSize) ve DB-side metrik hesaplama devreye alindi.
  • ✓Okuma agirlikli urun sorgularinda AsNoTracking uygulanarak EF tracking maliyeti azaltildi.
  • ✓Siparisler tablosu icin (OturumId, OlusturmaTarihi) composite index migration'i eklendi.

Canli Panellerde Soft Refresh Buyuk Guncelleme

  • ✓Kasa/Garson/Mutfak/Masa detay ekranlarinda SignalR olaylarinda tam sayfa reload yerine bolgesel soft refresh akisi uygulandi.
  • ✓Yalnizca hedef container icerigi yenilenerek flicker azaltilip kullanici akis durumu korundu (aktif tab/overlay).
  • ✓Event yogunlugu icin throttle + in-flight korumasi ile ust uste reload kaynakli performans kayiplari onlendi.

TR-EN Opsiyon Ceviri Dayanikliligi Kritik

  • ✓Opsiyon ad/grup alanlarinda AdEN/GrupEN bos birakilmis eski kayitlar icin merkezi fallback ceviri helper'i eklendi.
  • ✓Ilk render, modal akis ve /menu/json yaniti ayni ceviri mantigina baglandi; "Boyut" gibi metinlerde dil tutarliligi saglandi.
  • ✓Razor icindeki JS mesajlarinda entity bozulmasi Json serialize yaklasimi ile giderildi.

Ek olarak canli operasyon panellerinde tam reload yerine soft refresh modeline gecilerek performans ve akis surekliligi guclendirildi; oturum dogrulama ile TR-EN opsiyon cevirisinde gorulen kritik hata siniflari kalici olarak giderildi.
