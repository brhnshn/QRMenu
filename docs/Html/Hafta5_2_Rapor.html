3. Supabase Veritabanı Taşıma (Stockholm → Frankfurt)

3.1 Taşıma Süreci

Sebep: Eski Supabase instance (Stockholm, eu-north-1) silinmişti. Yeni instance Almanya (Frankfurt, eu-central-1) bölgesinde oluşturuldu. Tüm veriler CSV dosyalarından aktarıldı.

3.2 Karşılaşılan Sorunlar ve Çözümleri

Sorun Açıklama Çözüm
OVERRIDING SYSTEM VALUE Gereksinimi CSV'deki ID'ler ile PostgreSQL'in GENERATED ALWAYS AS IDENTITY kısıtlaması çakışıyordu. INSERT sorgularına OVERRIDING SYSTEM VALUE eklendi. FK kısıtlamalarını geçici devre dışı bırakmak için session_replication_role = 'replica' kullanıldı.
RowVersion NOT NULL Hatası CSV'deki boş RowVersion (byte[]) sütunları NOT NULL kısıtlamasını ihlal ediyordu. Binary değerler decode('0000000000000000', 'hex') ile dolduruldu.
Duplicate Key (Sequence) Hatası Veri aktarımından sonra PostgreSQL sequence sayaçları eski değerlerde kalmıştı. Tüm tablolar için setval() ile sequence'lar en yüksek ID değerine güncellendi.

3.3 Sequence Güncelleme Script'i

-- Tüm tablo sequence'larını en yüksek ID değerine güncelle
SELECT setval(pg_get_serial_sequence('"Masalar"', '"Id"'),
       COALESCE((SELECT MAX("Id") FROM "Masalar"), 1));
SELECT setval(pg_get_serial_sequence('"Siparisler"', '"Id"'),
       COALESCE((SELECT MAX("Id") FROM "Siparisler"), 1));
-- ... diğer tablolar için tekrarlandı

4. Ürün Görselleri — Veritabanından Dosya Sistemine Taşıma

4.1 Eski Mimari (Sorunlu)

Sorun: Görseller UrunGorseller tablosunda byte[] Data olarak binary saklanıyordu. Her görsel için ayrı DB sorgusu gerekiyordu (/images/urun/{id}). Admin panelinde ürünler sayfası açıldığında onlarca eş zamanlı DB isteği atılıyor, fotoğraflar gecikmeli yükleniyordu.

4.2 Yeni Mimari (Dosya Tabanlı)

📁 Kaydetme

  • Görseller wwwroot/uploads/urunler/{id}.{ext} olarak kaydediliyor
  • SaveImageToFileAsync() metodu: Max 2MB, jpg/png/webp
  • Eski dosya varsa otomatik temizleniyor
  • GorselUrl = "/uploads/urunler/5.jpg"

🔄 Geriye Dönük Uyumluluk

  • Eski /images/urun/{id} endpoint'i korundu
  • Önce static dosya arar → bulursa redirect
  • Bulamazsa DB'den serve eder (eski veriler)
  • Web sunucusu static dosyaları cache'leyerek sunar

4.3 Performans Karşılaştırması

6. Garson Paneli — "0 Ürün" Hatası Düzeltmesi

6.1 Kök Neden Analizi

Hata: Garson Masalar sayfasında (/Garson/Masalar) tüm masalarda "0 Ürün" yazıyordu.
Kök Neden: GarsonController.Masalar() sorgusu Siparisler'i include ediyordu ama SiparisDetaylar'ı include etmiyordu. View'da s.SiparisDetaylar.Sum(d => d.Adet) boş koleksiyon üzerinde çağrılınca hep 0 dönüyordu.

6.2 Çözüm

var masalar = await _context.Masalar
    .Include(m => m.Siparisler.Where(s => ...))
        .ThenInclude(s => s.SiparisDetaylar)  // ← EKLENDİ
    .OrderBy(m => m.MasaNo)
    .ToListAsync();

8. QR Giriş FK Hatası — MasaNo vs MasaId Karışıklığı

8.1 Kök Neden Analizi

Hata: Masa 5 ve 6'nın QR kodlarına girildiğinde FK_Oturumlar_Masalar_MasaId hatası veriyordu.
Kök Neden: QR URL /qr/{masaNo} formatında oluşturuluyordu (AdminController satır 116: $"{baseUrl}/qr/{masaNo}"). Ancak QRController bu değeri doğrudan MasaId olarak kullanıyordu. CSV'den aktarılan masalarda MasaNo=5 ama Id=7 olabiliyordu — bu FK ihlali oluşturuyordu.

8.2 Çözüm

// ÖNCE (Hatalı — masaNo'yu doğrudan MasaId olarak kullanıyor)
[HttpGet("/qr/{masaId:int}")]
public async Task<IActionResult> Index(int masaId)
{
    var (oturum, rawToken) = await _tokenService.CreateSessionAsync(masaId); // ← FK hatası!
}

// SONRA (Doğru — MasaNo ile DB lookup yapıyor)
[HttpGet("/qr/{masaNo:int}")]
public async Task<IActionResult> Index(int masaNo)
{
    var masa = await _context.Masalar
        .FirstOrDefaultAsync(m => m.MasaNo == masaNo && m.AktifMi);
    var masaId = masa.Id;  // ← Gerçek ID kullanılıyor
    var (oturum, rawToken) = await _tokenService.CreateSessionAsync(masaId);
}

10. Karşılaşılan Hatalar ve Çözümleri

Hata Kategori Çözüm
duplicate key value violates unique constraint DB / Sequence CSV aktarımından sonra PostgreSQL sequence sayaçları setval() ile güncellendi.
null value in column "RowVersion" violates not-null constraint DB / Concurrency RowVersion alanı decode('0000000000000000', 'hex') ile dolduruldu.
MaxClientsInSessionMode bağlantı hatası DB / Bağlantı Port 5432 → 6543 (Transaction Pooler) olarak değiştirildi.
FK_Oturumlar_Masalar_MasaId QR giriş hatası Backend / Mantık QRController'da MasaNo → DB lookup → gerçek MasaId akışı eklendi.
Garson panelinde tüm masalarda "0 Ürün" Gösterilmesi Backend / EF Core GarsonController.Masalar() sorgusuna .ThenInclude(s => s.SiparisDetaylar) eklendi.
Admin Masalar sayfasında tüm masalar "Boş" gösterilmesi Backend / Sorgu AdminController.Masalar() sorgusuna sipariş include eklendi, DoluMu property hesaplandı.
Ürün görselleri gecikmeli yükleniyor (Admin + Menü) Performans / Mimari Görseller DB (binary) → dosya sistemi (static file) olarak taşındı. DB yükü ortadan kalktı.
